## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting feature** available in this repository under the "Security" tab.

If you are unable to use that feature, please contact the repository maintainers directly. We appreciate your efforts to responsibly disclose your findings and will make every effort to acknowledge your report quickly.
