# Security Policy

## Supported Versions

Currently, only the latest version of the `Postal-Box-Manager` is supported with security updates.

## Reporting a Vulnerability

We take the security of `Postal-Box-Manager` seriously.

If you discover a security vulnerability, please **DO NOT** create a public issue. Instead, please report it privately to the maintainers.

### How to Report

Please use **GitHub's Private Vulnerability Reporting** feature to report any security issues.
You can find this feature in the "Security" tab of this repository, under "Advisories" -> "Report a vulnerability".

Alternatively, you can reach out directly to the active maintainers of this repository via their GitHub profiles.

We will endeavor to respond to all reports promptly and work with you to understand and resolve the issue. We ask that you do not disclose the vulnerability publicly until a fix has been released.
