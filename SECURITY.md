# Security Policy

## Supported Versions

The following versions of Postal-Box-Manager are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously.

If you discover a security vulnerability within this project, please report it via email to the project maintainers at `security@postal-box-manager.local` rather than creating a public issue.

You can expect to receive an initial response acknowledging the receipt of your report within 48 hours. If the vulnerability is verified, we will work on a patch and release it as quickly as possible. We will keep you updated on our progress and will notify you when the issue has been resolved.
