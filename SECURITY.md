| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager very seriously. If you discover a security vulnerability in this project, please report it to us confidentially.

**Do not publicly disclose the vulnerability until it has been addressed.**

### How to Report

Please report security vulnerabilities using **GitHub's Private Vulnerability Reporting** feature:
1. Go to the [Security tab](../../security) of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a detailed description of the issue, the steps to reproduce it, and its potential impact.

Alternatively, if you cannot use the Private Vulnerability Reporting feature, please contact the maintainers directly through their GitHub profiles.

We will acknowledge receipt of your vulnerability report and strive to address the issue as quickly as possible.
