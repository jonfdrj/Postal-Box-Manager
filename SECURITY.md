# Security Policy

## Supported Versions

Currently, only the latest version of the Postal Box Manager is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

We take the security of Postal Box Manager seriously. If you believe you have found a security vulnerability in this repository, please report it to us immediately.

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. If that is unavailable or inappropriate for your report, please reach out directly to the maintainers of this repository via their GitHub profiles.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, we expect that you will keep the issue confidential until we have had a chance to resolve it and release an update.
