# Security Policy

## Supported Versions

We are committed to resolving security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

Security is a priority for us. Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature.
To do this, navigate to the **Security** tab of this repository, then click **Advisories**, and choose **Report a vulnerability**.

Alternatively, you can contact the maintainers directly if you have their contact information.

We will try to respond to reports as quickly as possible.
