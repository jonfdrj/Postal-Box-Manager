# Security Policy

## Supported Versions

Currently, only the latest version of Postal-Box-Manager is supported with security updates.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability in this repository, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using [GitHub's Private Vulnerability Reporting feature](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability). Alternatively, you can contact the maintainers directly.

We will acknowledge receipt of your vulnerability report, and we will send you regular updates about our progress.
