# Security Policy

## Supported Versions

Currently, only the latest version of the project is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to us via GitHub's **Private Vulnerability Reporting** feature, which allows you to privately report a vulnerability directly to the repository maintainers.

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Provide a clear and detailed description of the issue, including steps to reproduce.

Alternatively, you can reach out directly to the maintainers if the above method is not suitable.

We take all security vulnerabilities seriously and will aim to respond to your report as quickly as possible.
