# Security Policy

## Supported Versions

Currently, the default branch receives security updates. If there are specific releases, the latest major version will be supported.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. To do this, go to the "Security" tab of this repository, then "Advisories", and click "Report a vulnerability".

If you are unable to use GitHub's Private Vulnerability Reporting feature, please contact the repository maintainers directly via their public profiles or reach out to them personally.
