# Security Policy

## Supported Versions

Please see the repository for information about which versions of the project are currently supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability, please report it via [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature.

Please do not report security vulnerabilities through public GitHub issues.

Once a report is submitted, we will acknowledge the report and work on a fix as quickly as possible.
