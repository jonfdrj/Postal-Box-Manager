# Security Policy

## Supported Versions

Currently, the latest version of the repository is supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability, please do **not** file a public issue. Instead, please report it securely using [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature.

To report a vulnerability:
1. Go to the "Security" tab of this repository.
2. Click on "Advisories" in the left sidebar.
3. Click the "Report a vulnerability" button.
4. Fill out the form with the details of the vulnerability.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
