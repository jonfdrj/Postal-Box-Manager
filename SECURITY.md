# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report it via [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature.

If that is not an option, please contact the maintainers directly through their public profiles. We will evaluate the report and work on a fix as quickly as possible.
