# Security Policy

## Supported Versions

Currently, only the latest version of Postal-Box-Manager is supported with security updates.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you discover a security vulnerability, please do not report it through public issues or pull requests.

Instead, please use GitHub's Private Vulnerability Reporting feature:
1. Go to the "Security" tab of this repository.
2. Click on "Advisories" in the left sidebar.
3. Click "Report a vulnerability".

Alternatively, you can reach out to the repository maintainers directly.

We will try to acknowledge your report as soon as possible and work with you to resolve the issue. Please do not publicly disclose the vulnerability until we have had a chance to fix it.
