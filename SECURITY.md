# Security Policy

## Supported Versions

Currently, only the latest version of this project is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. If that is not available, please contact the maintainers directly through their provided GitHub profile contact information.

We take security seriously and will make every effort to acknowledge your report and address the issue promptly.
