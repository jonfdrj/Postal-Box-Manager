# Security Policy

## Supported Versions

Currently, this repository is in initial development.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainers instead of opening a public issue. All security vulnerabilities will be promptly addressed.

Please include the following details in your report:
- A description of the vulnerability and its impact
- Steps to reproduce the vulnerability
- Any relevant logs or screenshots

We will evaluate your report and respond as quickly as possible.
