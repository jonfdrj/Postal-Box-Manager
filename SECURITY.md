## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability within this project, please report it via the GitHub private vulnerability reporting feature on the project repository.

Alternatively, if private vulnerability reporting is not enabled, please reach out to the project maintainers directly.

We will triage your report and respond as quickly as possible. Please avoid disclosing the vulnerability publicly until it has been resolved.
