# Security Policy

## Supported Versions

We only support the latest version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously.

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. To do so, go to the **Security** tab of this repository, select **Advisories**, and click **Report a vulnerability**.

You can also contact the maintainers directly through their public contact information on their GitHub profiles.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
