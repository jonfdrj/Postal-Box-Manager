# Security Policy

## Supported Versions

Please ensure you are using the latest version of the project before reporting any vulnerabilities.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's **Private Vulnerability Reporting** feature. You can access it by going to the "Security" tab in this repository, selecting "Advisories" (or "Vulnerability reporting"), and clicking "Report a vulnerability".

This allows us to receive the report privately, assess it, and provide a fix before the vulnerability becomes public.

Thank you for helping keep this project safe!
