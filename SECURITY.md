# Security Policy

## Supported Versions

Please use the latest version of Postal-Box-Manager to ensure you have all current security patches.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously.

If you discover a security vulnerability, please do not disclose it publicly. Instead, please use GitHub's Private Vulnerability Reporting feature to report the issue directly to the maintainers. We will review the report and work with you to resolve the issue as quickly as possible.
