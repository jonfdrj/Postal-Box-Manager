## Reporting a Vulnerability

We take the security of this project seriously.

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. If that is not available, please contact the maintainers directly through their GitHub profiles.

We will endeavor to respond to your report as quickly as possible, and keep you informed of our progress towards a fix.
