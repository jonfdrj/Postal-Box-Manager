# Security Policy

## Supported Versions

The following versions of Postal-Box-Manager are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to `security@example.com`.

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible depending on complexity.
