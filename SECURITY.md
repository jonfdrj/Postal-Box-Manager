# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues using GitHub's Private Vulnerability Reporting feature for this repository, or by contacting the repository maintainers directly.

Do not report security vulnerabilities through public GitHub issues.
