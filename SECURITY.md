# Security Policy

## Supported Versions

We currently support the latest version of the project on the main branch for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by opening an issue in this repository.

For sensitive or critical vulnerabilities that you feel should not be disclosed publicly immediately, please contact the repository maintainers directly via their GitHub profiles.

We take all security vulnerabilities seriously and will aim to respond and resolve issues as quickly as possible.
