## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's Private Vulnerability Reporting feature if available on this repository, or contact the project maintainers directly via their GitHub profiles or through direct communication channels if provided.

Upon receiving your report, we will try to acknowledge it within 48 hours. We will work with you to understand the issue, provide a timeline for a fix, and responsibly disclose the vulnerability once it is resolved.
