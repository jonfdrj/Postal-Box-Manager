# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities to `security@example.com`.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.

If your vulnerability is accepted, we will coordinate with you to publish a fix and a security advisory.
