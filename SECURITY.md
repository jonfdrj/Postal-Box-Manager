## Reporting a Vulnerability

Security is a top priority for us. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via **GitHub's Private Vulnerability Reporting** feature. This allows us to work together to verify and fix the vulnerability before any details are made public.

To use this feature:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a detailed description of the issue, including steps to reproduce.

Alternatively, you can contact the repository maintainers directly.

We take all security reports seriously and will strive to investigate and address them promptly.
