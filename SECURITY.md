# Security Policy

## Supported Versions

Currently, the latest version of Postal-Box-Manager is supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

If you believe you have found a security vulnerability, please report it via **GitHub's Private Vulnerability Reporting** feature. This allows us to securely investigate and address the issue before it becomes public.

Alternatively, you can contact the maintainers directly.

Please do not use public issues to report security vulnerabilities, as this could expose the project and its users to unnecessary risk before a fix is available.
