# Security Policy

## Supported Versions

We currently only support the latest version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. We take all security vulnerabilities seriously and will address them as quickly as possible.

To report a vulnerability:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click on the **Report a vulnerability** button.
4. Fill in the details of the vulnerability and submit the report.

Thank you for helping keep this project secure!
