# Security Policy

## Supported Versions

Currently, only the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously.

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature by navigating to the "Security" tab in this repository, then "Advisories", and clicking "Report a vulnerability".

Alternatively, if that feature is not available, please contact the maintainers directly through their public GitHub profiles.

We will endeavor to respond to your report promptly.
