# Security Policy

## Supported Versions

Currently, only the latest version of Postal-Box-Manager is supported with security updates.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability, please do not report it through public GitHub issues.

Instead, please report the vulnerability using [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature on this repository. Alternatively, you can contact the maintainers directly via their GitHub profiles.

Please include the following information in your report:
* A description of the vulnerability and its impact.
* Steps to reproduce the vulnerability.
* Any relevant background information or technical details.

We will acknowledge receipt of your vulnerability report and strive to address it promptly.
