# Security Policy for Postal-Box-Manager

## Supported Versions

We currently provide security updates for the `main` branch of Postal-Box-Manager.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you discover a security vulnerability, please bring it to our attention right away!

Please **DO NOT** open a public issue. Instead, report security vulnerabilities by creating a private GitHub Security Advisory in this repository, or by contacting the repository owners directly.

We will attempt to respond to your report within 48 hours. When reporting, please provide:
* A detailed description of the vulnerability.
* Steps to reproduce the vulnerability.
* Any possible proof of concept code or logs.

Thank you for helping keep our project secure!
