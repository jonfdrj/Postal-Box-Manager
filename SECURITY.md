| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please use GitHub's Private Vulnerability Reporting feature to report any security vulnerabilities. Navigate to the "Security" tab of this repository, select "Advisories", and then "Report a vulnerability".

Alternatively, you can reach out to the project maintainers directly via their GitHub profiles.
