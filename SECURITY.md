# Security Policy

## Supported Versions

We currently support the latest version of this project with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using GitHub's Private Vulnerability Reporting feature. Go to the "Security" tab in this repository, and click on "Report a vulnerability".

Alternatively, if you know the maintainers, please contact them directly.
