# Security Policy

## Supported Versions

Currently, only the latest version of Postal-Box-Manager is supported with security updates.

## Reporting a Vulnerability

We take the security of Postal-Box-Manager seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using **GitHub's Private Vulnerability Reporting feature**. This allows you to privately report vulnerabilities directly to the maintainers, ensuring they can be addressed securely before public disclosure.

Alternatively, if you know the maintainers personally, you may contact them directly via secure channels.
