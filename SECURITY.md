# Security Policy

## Supported Versions

Currently, the main branch of this project is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. If that is not available, please contact the maintainers directly.

1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide a detailed description of the vulnerability, including steps to reproduce, potential impact, and any potential mitigation strategies.

The maintainers will acknowledge receipt of your vulnerability report and strive to address it in a timely manner.
