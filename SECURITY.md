## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do not disclose it publicly.

Instead, please report it using [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature on this repository. Alternatively, you can contact the project maintainers directly via their public contact channels if provided.

Please provide as much detail as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We will endeavor to respond to all reports in a timely manner and keep you informed of our progress towards a fix and announcement.
